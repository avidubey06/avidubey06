AI Triage Output Evaluator

Check whether a structured summary is supported by its evidence.

Synthetic lab result

1 unsupported claim caught

Problem and audience

An analyst needs a way to tell which claims in a summary can be traced to case evidence. The evaluator takes labeled cases and candidate outputs with structured evidence citations.

Implementation

The evaluator matches evidence ID, field, and value, producing severity agreement, unsupported-claim rate, required-evidence recall and per-case differences.

Python · JSON · evidence matching

Validation and results

The flawed handwritten fixture matched severity on 3 of 4 cases and covered 6 of 8 required facts. It claimed MFA was bypassed while the evidence recorded an unknown result.

Limitations and lessons

Exact matching supports structured output. Handwritten fixtures validate the scoring logic. Model-generated JSON can be evaluated separately.
