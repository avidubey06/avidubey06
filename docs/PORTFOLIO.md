# Portfolio design and deployment

## Creative directions

- **Intelligence Core** uses charcoal, lime, and violet with a large typographic hero and a projected geometric model. It connects systems and evidence to the case studies. Selected for clarity and low dependency cost.
- **Field Notes** uses ivory and ink, editorial serif typography, and a layered evidence drawer. Excellent for reading, with less emphasis on motion.
- **Systems Atlas** uses cobalt and silver with a full-screen topology map. Strong for exploration, with more navigation overhead.

## Run and publish

From the repository root run `python -m http.server --directory docs` and open the local URL printed by Python. The site uses static HTML, CSS, and JavaScript. There are no dependencies or environment variables. Publish from `main`, folder `/docs`, in Settings → Pages.

The work pages cover investigation, detection tuning, and AI output validation. The home page contains a synthetic-case walkthrough. The résumé is a public HTML edition. Email and LinkedIn are direct links. The original private résumé file is not part of the site.

The geometry is original and drawn in the browser. It uses perspective projection on Canvas and honors reduced motion. There are no external artwork assets.
